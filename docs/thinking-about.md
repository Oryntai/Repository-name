1. Канвас (Frontend)
Не пишите канвас с нуля — используйте tldraw (React-библиотека). Она даёт из коробки: фигуры, стикеры, рисование, drag & drop, зум, и — главное — кастомные shape'ы. Через кастомные shape'ы вы добавите элементы агента (стикеры с AI-меткой, сгенерированные картинки, группировки).
Альтернативы: Excalidraw (проще, но менее гибкий API), react-flow (хорош для графов, но не для свободного канваса).
2. Real-time синхронизация
Ядро — Yjs (CRDT-библиотека). Каждый элемент канваса — это запись в Yjs document (Y.Map). Все клиенты (и агент!) подключаются к одному y-websocket серверу. Это значит, что агент — это просто ещё один Yjs-клиент, который читает и пишет в тот же документ. Никакого отдельного API для агента не нужно.
Presence (курсоры, имена) тоже идёт через Yjs awareness protocol — агент может показывать свой курсор, когда «думает» или перемещает элемент.
3. Оркестратор агента
Это самая важная часть. Агент — это серверный процесс, который:
Наблюдает — подписывается на изменения Yjs-документа. При каждом изменении получает diff: «пользователь добавил стикер с текстом X», «пользователь переместил группу Y».
Решает — не на каждое действие нужно реагировать. Trigger manager фильтрует: debounce (ждём 3-5 секунд паузы), cooldown (не чаще раза в 30 секунд), а также проверяет, обращался ли пользователь к агенту напрямую (@agent или голосом).
Формирует контекст — context builder сериализует текущее состояние канваса в текстовый prompt для LLM. Это ключевая инженерная задача. Примерный формат:
Canvas state:
- Sticky "Problem: low retention" at (200, 100), color: yellow
- Sticky "Idea: onboarding flow" at (400, 100), color: green  
- Group "User Pain Points" contains: [sticky1, sticky2]
- Arrow from sticky1 → sticky2

Recent actions (last 60s):
- User A added sticky "gamification?"
- User B moved sticky1 into group "Solutions"

User message: "@agent suggest 3 more ideas related to retention"
Выполняет — получает ответ от LLM (структурированный JSON: «создай стикер с текстом X на позиции Y, цвет Z»), парсит его и записывает в Yjs-документ. Элементы появляются на канвасе у всех клиентов мгновенно.
4. Голос
Для голосового ввода — Web Speech API (бесплатно, работает в Chrome) или Whisper API. Транскрипт добавляется в контекст агента так же, как текстовые команды. Не нужно делать full duplex voice — достаточно push-to-talk.
5. Медиа-генерация
Когда агент (или пользователь) хочет визуализировать идею, оркестратор вызывает Higgsfield API, получает URL картинки/видео, и добавляет на канвас как кастомный shape (image node с URL). Элемент сразу становится перемещаемым и масштабируемым.
Стек в итоге
Frontend: React + tldraw + Yjs provider, плюс Web Speech API для голоса. Backend: Node.js сервер с y-websocket для синхронизации и отдельный процесс (Node или Python) для оркестратора агента. Внешние сервисы: любой LLM через API и Higgsfield для медиа.
